Try the account timezone flow

  1. Sign in. Use demouser / demopassword on the demo profile. This is a shared teaching account.
  2. Save an account timezone. Select a zone on the profile. Event display follows that saved setting across visits; UTC timestamps stay unchanged.
  3. Compare events. Try New York, Los Angeles, and Tokyo. The winter/summer examples show DST differences; the near-midnight event can change calendar date.
  4. Simulate travel. Change the “Simulated browser timezone” dropdown. It exercises detection without changing your device settings.
  5. Accept or dismiss. The popup suggests the new timezone. Only acceptance updates your account. Repeat the same from → to transition to see it suppressed in this browser session.

This demo uses saved account time + opt-in suggestions. “Follow device automatically” is a different valid product choice; Google Calendar offers that option. The inspector below remains anonymous and read-only.
